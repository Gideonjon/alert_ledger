# alert_ledger

Flutter app configured to connect to the Appwrite project `alert_ledger`.

The Appwrite Flutter SDK is declared in `pubspec.yaml`. The app uses project ID
`6ae112f6002b84c4affc` at `https://fra.cloud.appwrite.io/v1`. Launch the app
and tap **Ping Appwrite** to verify connectivity; the result is shown below the
button.
